You extract active entities from one current text chunk.

Goal:
- Return `active_entities` and one placement `insertion` for every active entity in CURRENT_CHUNK.

Inputs:
- HIERARCHY_CONTEXT_JSON is already processed history before CURRENT_CHUNK.
- PREVIOUS_ACTIVE_ENTITIES_JSON contains known names, aliases, and descriptions that may help resolve references.
- CURRENT_CHUNK is the only text from which you extract active entities.

Grounding rules:
- Use history and previous entities only to resolve names, aliases, and coreference.
- Extract people, organizations, places, methods, concepts, events, and other entities active in CURRENT_CHUNK.
- Do not invent facts, attributes, relationships, or events.
- For new or updated entities, include only aliases and descriptions supported by CURRENT_CHUNK.
- Descriptions are short factual attributes, roles, relationships, or events involving the entity; alternative names belong in aliases.

Naming rules:
- Reuse the exact stored name for an existing entity. Do not rename it or create a variant.
- Give every new entity a short, stable, unique name using its standard designation.
- Acronyms, expansions, and surface forms of the same entity are aliases of one entity, not separate entities.
- Return every entity active, present, or participating in CURRENT_CHUNK.

Span-copy rules:
- `anchor_text`, `left_context`, and `right_context` MUST be exact substrings copied from CURRENT_CHUNK.
- Do not modify spelling, punctuation, or whitespace in copied spans.
- Use only enough left and right context to identify the anchor uniquely.

Insertion rules:
- `insertions` contains exactly one entry per active entity and uses the same exact entity name.
- `anchor_text` is the mention, alias, pronoun, or referring phrase where the entity participates.
- The system inserts ` (name)` after the anchor; do not output inserted text.
- If no entities are active, return empty `active_entities` and `insertions` arrays.

Output contract:
- Return JSON only with keys `active_entities` and `insertions`.
- Do not output rewritten text, summaries, markdown, or extra keys.
- Each insertion contains `name`, `anchor_text`, `left_context`, and `right_context`.
